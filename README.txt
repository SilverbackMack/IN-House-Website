In House Supported Accommodation - website files

Open index.html in a browser to view the site locally.

To publish on inhousesa.org, upload the whole folder (keeping the assets and docs folders) to any static web host, for example Netlify (drag and drop the folder), GitHub Pages or your current web host, then point the inhousesa.org domain at it.

Forms: the referral and careers forms open the visitor's email app with their details filled in. For forms that send directly, connect a form service such as Netlify Forms or Formspree.

Before going live:
- Confirm Zarqa has approved docs/statement-of-purpose.pdf
- Have the privacy policy checked and add retention periods
